# 🌤️ Real-Time Weather Application

A clean, responsive web application that provides real-time weather information for cities around the globe. Built using vanilla JavaScript, modern Async/Await techniques, OpenWeatherMap API.

---

## ✨ Features

* **Live Weather Data:** Fetches real-time temperature, weather conditions, and wind speed.
* **Smart Error Handling:** Friendly notifications for invalid city names or API connection issues.


---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3
* **Logic:** Modern JavaScript (ES6+, Async/Await, Fetch API)
* **API:** [OpenWeatherMap API](https://openweathermap.org/)
